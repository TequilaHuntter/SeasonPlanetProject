# 专注星球原型 v0.1

打开 dist/index.html 可本地试玩；建议以发布后的网页地址体验，存档跟随当前浏览器及网址，不会跨设备同步。

1. 点击星球上的一块空地。
2. 购买种子，再点击种植，可种满四块土地。
3. 勾选“快速试玩”可用10秒体验一季；不勾选则为30分钟。
4. 开始专注，完成后自动结算一季。切换页面会暂停，返回后手动继续。
5. 出售仓库作物可获得金币；改善生态后可出售星球，得到一颗初始星球。

此版使用程序绘制的占位美术和六种示例植物。Excel 配置表尚需开发者转换后更新到游戏，不支持直接导入。

这是网页原型，暂不含桌宠悬浮窗口。存档为本地数据，清除浏览器数据会丢失。快速试玩和正式计时共用存档，试玩收益会保留。
